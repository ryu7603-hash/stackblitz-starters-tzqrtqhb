# はじめに

台所にある砂糖、塩、酢、醤油、味噌。いつから同じものを買い続けているでしょうか。

多くの人にとって調味料は「なくなったら同じものを買い足すもの」です。違う商品が気になっても、1本買って口に合わなかったらもったいない。使い切るまで何か月もかかる。だから結局、いつもの一本に手が伸びる。

でも、調味料は料理の味を決める土台です。肉や野菜を変えるより、調味料を一つ変えるほうが、毎日の食卓はずっと大きく変わります。

この本は、そんな「変えてみたいけど、一歩が出ない」人のための入門書です。料理の基本といわれる「さしすせそ」――砂糖・塩・酢・醤油（せうゆ）・味噌――の5つについて、

- どんな種類があって、何が違うのか
- 家でどうやって食べ比べればいいのか
- 自分の好みが分かったら、どう選べばいいのか

を、なるべく短く、すぐ試せる形でまとめました。

難しい知識は必要ありません。小皿といくつかの調味料があれば、今日の夕食から始められます。

# 第1章　食べ比べの基本

## 違いは「並べる」と分かる

調味料の違いは、単体で味わってもなかなか分かりません。人間の舌は「比べる」ことで違いに気づきます。ですから、食べ比べのコツは、とにかく**同じ条件で並べること**です。

## 用意するもの

- 比べたい調味料（2〜4種類がちょうどいい）
- 白い小皿（色が見やすい）
- 味のシンプルな食材（白いご飯、豆腐、ゆで野菜、きゅうりなど）
- 口直しの水、またはぬるめのお茶
- メモ（巻末の記録シートが使えます）

5種類以上を一度に比べると、舌が疲れて違いが分からなくなります。最初は2種類、慣れても4種類までにしておきましょう。

## 基本の手順

1. **見る**　白い小皿に少量ずつ出し、色やとろみを比べます。
2. **香る**　小皿を鼻に近づけて香りをかぎます。香りは時間とともに飛ぶので、出してすぐがおすすめです。
3. **そのまま味わう**　ほんの少しを舌にのせ、塩味・甘み・酸味・旨味・後味を比べます。
4. **食材と合わせる**　同じ食材につけたり、かけたりして食べます。単体の印象と大きく変わることも多く、ここがいちばん面白いところです。
5. **記録する**　感じたことを一言ずつメモします。

一つ味わうごとに水で口をリセットしましょう。順番は、味の穏やかなものから強いものへ進むのが基本です。

## ブラインドで遊ぶ

家族や友人がいるなら、誰かに小皿を並べ替えてもらい、どれが「いつもの調味料」か当ててみてください。

意外なほど当たりません。そして、当たらなかったことが「思い込みで選んでいた」ことに気づくきっかけになります。正解を知ったうえでもう一度味わうと、違いがはっきり分かるようになるのも面白い体験です。

## 「好き」を言葉にするコツ

「おいしい」「普通」だけでは、次に選ぶときの手がかりになりません。次のような軸で、どちら寄りかを考えてみましょう。

- 塩味が　強い ／ 穏やか
- 甘みが　ある ／ ない
- 香りが　華やか ／ 控えめ
- 後味が　すっきり ／ 長く残る
- 全体が　軽い ／ 重い・濃厚

この軸で何種類か比べていくと、「自分はすっきり系が好き」「料理によっては濃厚なほうがいい」といった傾向が見えてきます。

# 第2章　砂糖（さ）

## 砂糖の主な種類

| 種類 | 特徴 |
|---|---|
| 上白糖 | 日本の家庭で最も一般的。しっとりしていて、コクのある甘さ |
| グラニュー糖 | サラサラで、すっきりとしたクセのない甘さ |
| 三温糖 | 薄い茶色。カラメルのような香ばしさとコク |
| きび砂糖 | さとうきびの風味を残した、まろやかな甘さ |
| 黒糖 | さとうきびの汁を煮詰めたもの。独特の濃い風味とミネラル感 |

## 食べ比べのポイント

砂糖は、そのまま舐めると違いが分かりにくい調味料です。おすすめは**ぬるま湯に溶かして比べる**方法です。同じ量の砂糖を同じ量のお湯に溶かすと、甘さの質や香りの違いが驚くほどはっきりします。

もう一つの方法は、無糖のヨーグルトやホットミルクに混ぜることです。乳製品と合わせると、きび砂糖や黒糖の風味がよく引き立ちます。

## 使い分けのヒント

- 甘さだけを足したい（紅茶、洋菓子）→ グラニュー糖
- 煮物にコクを出したい → 三温糖、きび砂糖
- 素朴な風味を楽しみたい（おやつ、煮豆）→ 黒糖

## やってみよう

上白糖とグラニュー糖を、同じ量ずつぬるま湯に溶かして飲み比べてみましょう。上白糖のほうが「しっとり重い甘さ」、グラニュー糖のほうが「軽くすっきりした甘さ」に感じる人が多いはずです。余裕があれば、きび砂糖を加えて3種類で比べてみてください。

# 第3章　塩（し）

## 塩の主な種類

塩は「どこから採ったか」と「どう作ったか」で個性が変わります。

**原料による違い**

- **海塩**　海水から作る塩。日本の塩の多くはこれです。
- **岩塩**　大昔の海水が地中で結晶になったもの。
- **湖塩**　塩分を含む湖から採る塩。

**製法による違い**

- **精製塩**　塩化ナトリウムの純度が非常に高く、しょっぱさがストレート。
- **平釜塩**　海水を釜で煮詰めて作る。粒の形がさまざまで、にがり成分が残りやすい。
- **天日塩**　太陽と風で水分を飛ばして作る。

にがり成分（マグネシウムなど）が多く残る塩は、しょっぱさの中に甘みや苦みを感じやすくなります。

## 食べ比べのポイント

塩の食べ比べに最適なのは、**ゆで野菜、トマト、ゆで卵、白いおにぎり**です。素材の味がシンプルなほど、塩の違いが前に出ます。

ひとつまみをそのまま舐めると、「角が立ったしょっぱさ」と「丸いしょっぱさ」の違いが分かるはずです。粒の大きさによって溶けるスピードが違い、舌の上での広がり方も変わります。

## 使い分けのヒント

- パスタのゆで湯、下味 → 溶けやすく安定した精製塩や細かい粒の塩
- 天ぷら、ステーキ、おにぎり → 粒感や風味を楽しめる塩
- 甘みのある塩は、トマトやスイカなど甘い素材とよく合う

## やってみよう

ゆで卵を半分に切り、片方には家にある塩、もう片方には別の塩（粒の大きいものや、にがりの多いもの）をふって食べ比べてみましょう。同じ卵なのに、塩味の立ち方や後味がはっきり変わります。

# 第4章　酢（す）

## 酢の主な種類

| 種類 | 特徴 |
|---|---|
| 穀物酢 | 小麦・米・とうもろこしなどの穀物が原料。クセがなく、すっきりとした酸味 |
| 米酢 | 米を多く使った酢。まろやかで、ふくよかな香り |
| 純米酢 | 原料に米だけを使った酢。米酢より旨味が強い傾向 |
| 黒酢 | 長期熟成で色が濃くなった酢。まろやかでコクがある |
| りんご酢 | 果実の香りがあり、フルーティーで軽い酸味 |

## 食べ比べのポイント

酢をそのまま口に含むと刺激が強すぎるので、**水で数倍に薄めて**比べましょう。酸味の強さよりも、「香り」と「後味」に注目するのがコツです。

食材と合わせるなら、**きゅうりの酢の物**がいちばん分かりやすい組み合わせです。同じ量の砂糖と塩を加えた合わせ酢を作り、酢の種類だけを変えて比べてみてください。

## 使い分けのヒント

- 酢の物、ピクルス（すっきり仕上げたい）→ 穀物酢
- すし飯、和え物 → 米酢、純米酢
- 酢豚、炒め物、肉の煮込み → 黒酢
- ドレッシング、飲む酢 → りんご酢などの果実酢

## やってみよう

穀物酢と米酢で、それぞれきゅうりの酢の物を作ってみましょう。砂糖と塩の量はまったく同じにします。穀物酢はキリッとした酸味、米酢はまろやかで甘みを感じる仕上がりになり、「酢の物が苦手」という人が米酢なら食べられることもあります。

# 第5章　醤油（せ）

## 醤油の5つのタイプ

醤油は日本農林規格（JAS）で5つのタイプに分けられています。

| タイプ | 特徴 |
|---|---|
| 濃口 | いわゆる普通の醤油。香り・旨味・塩味のバランスがよく、何にでも合う |
| 淡口 | 色が淡く、素材の色を活かせる。色は薄くても塩分は濃口よりやや高め |
| 溜 | 大豆中心で造る、とろみのある濃厚な醤油。中部地方で多く造られる |
| 再仕込 | 塩水の代わりに醤油で仕込む。色も味も濃く、まろやか |
| 白 | 小麦中心で造る、ごく淡い色の醤油。甘みと独特の香り |

同じタイプでも、蔵や仕込み方（木桶か、熟成期間はどれくらいか）によって味は大きく変わります。また、加熱処理をしていない「生醤油」は、香りがフレッシュで色が明るいのが特徴です。

## 食べ比べのポイント

醤油の違いが最も分かりやすいのは、**冷奴と白いご飯**です。豆腐に数滴たらすだけで、香りの立ち方や塩味の角の違いがよく分かります。

刺身があれば、ぜひ再仕込や溜と、いつもの濃口を比べてみてください。魚の脂との相性が大きく変わり、「刺身醤油」がなぜ別にあるのかを実感できます。

## 使い分けのヒント

- 卵かけご飯、炒め物 → 濃口
- お吸い物、うどんつゆ、炊き込みご飯 → 淡口
- 刺身、照り焼き → 溜、再仕込
- 茶碗蒸し、色を付けたくない煮物 → 白

最初の「2本目」には、濃口との違いがはっきりしている再仕込か白がおすすめです。

## やってみよう

冷奴を2つ用意し、いつもの濃口醤油と、再仕込醤油（または溜醤油）を数滴ずつたらして食べ比べてみましょう。再仕込や溜は、少量でも旨味と甘みがしっかり感じられるはずです。

# 第6章　味噌（そ）

## 味噌の主な種類

味噌は、大豆に加える「麹」の種類で大きく3つに分けられます。

| 種類 | 特徴 |
|---|---|
| 米味噌 | 米麹で造る。日本で最も多く造られている |
| 麦味噌 | 麦麹で造る。麦の香ばしい香りと甘み。九州・四国・中国地方で多い |
| 豆味噌 | 大豆と豆麹で造る。濃厚な旨味と渋み。東海地方で多い |

複数の味噌を合わせたものは「調合味噌」と呼ばれます。

## 色と味の違い

味噌の色は、白っぽいものから赤褐色のものまでさまざまです。一般に、熟成期間が長いほど色は濃くなり、味わいも深くなります。

甘口か辛口かは、主に**麹の割合**と**塩分**で決まります。麹が多いほど甘口になり、京都の白味噌のように甘みの強いものもあります。

## 食べ比べのポイント

味噌はやはり**味噌汁**で比べるのがいちばんです。同じだしを用意し、具は豆腐とねぎ程度のシンプルなものにして、味噌だけを変えてみましょう。

もう一つのおすすめは、**きゅうりに直接つける**方法です。味噌そのものの香りと塩味がストレートに分かります。

## 使い分けのヒント

- 毎日の味噌汁 → 好みの米味噌を軸に
- 甘い味噌汁、西京焼き → 白味噌
- 味噌煮込み、味噌カツのたれ → 豆味噌
- 何種類か混ぜて「自分の合わせ味噌」を作るのも楽しい

## やってみよう

小さな鍋を2つ用意して同じだしを温め、それぞれに違う味噌を溶いて味噌汁を作りましょう。米味噌と麦味噌、あるいは米味噌と豆味噌の組み合わせがおすすめです。香りの違いは、お椀に注いだ直後がいちばんよく分かります。

# 第7章　番外編・みりん

「さしすせそ」には入りませんが、和食に欠かせないのがみりんです。実は、店頭には性質のまったく違う3種類が並んでいます。

| 種類 | 特徴 |
|---|---|
| 本みりん | もち米・米麹・焼酎などから造る。アルコール分を約14%含む酒類 |
| みりん風調味料 | 糖類などで味を似せたもの。アルコール分はほとんど含まない |
| 発酵調味料（みりんタイプ） | アルコールを含むが、塩を加えて飲用できないようにしたもの |

本みりんは、上品な甘み、照り、煮崩れ防止、臭み消しなど、多くの役割を持っています。みりん風調味料はアルコールを含まないため、煮切る必要がなく手軽に使えます。

比べるなら、**少量を小鍋で煮切って**から舐めてみましょう。甘みの質と香りの違いがよく分かります。照り焼きを2種類のみりんで作り比べるのもおすすめです。

# 第8章　食べ比べ会を開こう

調味料の食べ比べは、一人より大勢でやるほうが盛り上がります。最後に、家で開ける「食べ比べ会」のプランを紹介します。

## 準備（30分）

- テーマを1つ決める（例：「醤油3種」「塩3種」）
- それぞれの調味料に番号を振った小皿を用意する
- 合わせる食材を2〜3品用意する（冷奴、ゆで野菜、白いご飯など）
- 参加者分の記録シートとペン

## 進め方（30〜60分）

1. 番号だけを見せて、ブラインドで全種類を味わう
2. 各自が記録シートに感想と「一番好きなもの」を書く
3. 一斉に「好きな番号」を発表する
4. 正体を明かし、値段や産地も発表する
5. 好みが分かれた理由をみんなで話す

高い調味料が選ばれるとは限りません。普段の調味料が一番人気になることもよくあります。それも含めて、「好みは人それぞれ」と分かることがこの会の醍醐味です。

## 余った調味料の使い道

食べ比べ用に買った調味料が余ったら、それぞれ得意な料理に回しましょう。この本の「使い分けのヒント」を参考にすれば、無駄なく使い切れます。

# 第9章　ラベルの見方

食べ比べで好みが分かってきたら、次はお店で選ぶ番です。調味料のラベルには、選ぶための手がかりがたくさん書かれています。

## 原材料は「多い順」

食品の原材料名は、使っている重量の多い順に書かれています。たとえば醤油で「大豆」が「小麦」より先に書かれていれば大豆が多め、逆なら小麦が多めということです。大豆が多いほど旨味が強く、小麦が多いほど香りと甘みが出やすい傾向があります。

## 醤油のラベル

- **種類**　濃口・淡口・溜・再仕込・白のどれかが書かれています。
- **製造方式**　「本醸造」は、麹菌の力だけでじっくり発酵・熟成させる伝統的な造り方です。
- **等級**　JASでは「特級」「上級」「標準」の等級があり、旨味成分などの基準で分けられています。「特選」「超特選」は、特級の基準をさらに上回るものに付けられる表示です。

## 味噌のラベル

- **原材料**　米・麦・大豆のどれが書かれているかで、米味噌・麦味噌・豆味噌が分かります。
- **天然醸造**　温度を上げて発酵を早める方法を使わず、添加物も使わずに造った味噌に付けられる表示です。

## 酢のラベル

- **品名**　「穀物酢」「米酢」「米黒酢」「りんご酢」など、原料によって名前が決まっています。
- **酸度**　酸っぱさの目安です。同じ種類でも、酸度が高いほど酸味がシャープになります。

## みりんのラベル

- **品目**　「本みりん」は酒類として売られています。「みりん風調味料」「発酵調味料」は別のものなので、使い方の違いに注意しましょう。

# 第10章　保存のコツ

せっかく選んだ調味料も、保存の仕方で風味が大きく変わります。

## 醤油

醤油は開封すると空気に触れて酸化が進み、色が濃くなって香りが落ちていきます。開封後は**冷蔵庫で保存**し、なるべく早めに使い切りましょう。最近は、空気に触れにくい二重構造の容器に入った醤油も多く売られています。食べ比べのためにいろいろ買うなら、**小さいサイズ**を選ぶのも鮮度を保つコツです。

## 味噌

味噌は冷蔵庫で保存します。表面が空気に触れないよう、ラップを密着させておくと風味が長持ちします。塩分があるため冷凍庫でもカチカチには凍りにくく、冷凍保存して使う人もいます。

## 酢

酢は保存性の高い調味料なので、開封後も常温の冷暗所で保存できます。ただし香りは少しずつ飛ぶので、キャップはしっかり閉めましょう。

## 砂糖・塩

砂糖と塩は品質の変化がとても少ないため、賞味期限の表示が省略されていることがあります。湿気を吸って固まりやすいので、密閉容器に入れて保存しましょう。

## みりん

本みりんは常温の冷暗所で保存します。冷蔵庫に入れると、糖分が結晶になって出てくることがあります。一方、みりん風調味料は開封後に冷蔵保存が必要なものが多いので、ラベルの表示を確認しましょう。

# 第11章　よくある質問

**Q. 高い調味料ほどおいしいのですか？**

A. 必ずしもそうではありません。手間のかかる造り方をした調味料は価格が上がりますが、「おいしい」と感じるかは好みと料理との相性次第です。ブラインドで食べ比べると、普段の調味料が一番人気になることも珍しくありません。

**Q. 食べ比べ用に何本も買うと、使い切れません。**

A. 小容量のボトルや、お試しセットを活用しましょう。最近は醤油や味噌でも、少量ずつ数種類が入ったセットが増えています。また、家族や友人と分け合うのもおすすめです。

**Q. 子どもと一緒にやっても大丈夫ですか？**

A. 砂糖・塩・醤油・味噌の食べ比べは、子どもにも分かりやすく、食育にもなります。ただし本みりんはアルコールを含むので、煮切らずに子どもが口にすることがないよう注意してください。

**Q. 違いがまったく分かりません。**

A. 最初はそれが普通です。比べる種類を2つに減らし、タイプの違いがはっきりしたもの（濃口と白醤油、米味噌と豆味噌など）から始めてみてください。何度か繰り返すうちに、少しずつ違いが分かるようになります。

**Q. 減塩の調味料はおいしくないのでは？**

A. 減塩タイプは、旨味やだしを工夫して物足りなさを補っているものが多くあります。気になる方は、通常品と減塩品を並べて食べ比べてみてください。思ったより差が小さいと感じるかもしれません。

# おわりに

調味料を変えるのは、料理の腕を上げるよりずっと簡単で、効果の大きい方法です。

大切なのは、「高いもの」「有名なもの」を探すことではなく、**自分の舌で比べて、自分の好みを知ること**です。好みが分かれば、店頭に並ぶたくさんの調味料の中から、迷わず選べるようになります。

まずは今夜、冷奴に2種類の醤油をたらすところから始めてみてください。いつもの食卓が、少しだけ楽しくなるはずです。

醤油の食べ比べをもっと楽しみたい方は、ウェブサイト「味くらべ」の醤油タイプ診断もぜひお試しください。
