# Kindle出版ガイド（さしすせそ食べ比べ入門）

## ファイル

- `sashisuseso.epub` … 本文（KDPにそのままアップロード）
- `cover.jpg` … 表紙（1600×2560px）
- `manuscript.md` … 原稿。直したら下のコマンドでEPUBを作り直す

```bash
pandoc manuscript.md -o sashisuseso.epub --toc --toc-depth=1 --split-level=1 \
  --epub-cover-image=cover.jpg --css=style.css
```

## 出版手順（約1時間）

1. https://kdp.amazon.co.jp/ にAmazonアカウントでログイン
2. アカウント情報で、銀行口座と税務情報（日本在住ならマイナンバー不要の簡単な質問）を登録
3. 「電子書籍を作成」から、下の内容を入力
4. 原稿に `sashisuseso.epub`、表紙に `cover.jpg` をアップロードし、プレビューアーで確認
5. 価格を設定して出版（審査は通常72時間以内）

## 入力内容

- **タイトル**: いつもの調味料、変えてみる。
- **サブタイトル**: さしすせそ食べ比べ入門
- **著者**: 味くらべ編集部（本名でもペンネームでも可）
- **言語**: 日本語
- **キーワード（最大7個）**: 調味料, 食べ比べ, 醤油, 味噌, 塩, 酢, 食育
- **カテゴリ**: 料理・レシピ ＞ 調味料・スパイス / 暮らし・健康 ＞ 食生活
- **KDPセレクト**: 登録する（Kindle Unlimited の読み放題で読まれたページ数に応じて報酬が入る）
  - 登録中の90日間は、この本の電子版を他で販売・無料公開できない。サイトの記事とは内容を分けてあるので問題なし
- **価格**: 300円、ロイヤリティ70%（日本では250〜1,250円の範囲で70%を選べる）

## 売るための一手間（任意）

- 出版後、Amazonの商品ページURL（Amazonアソシエイトのリンクなら紹介料も入る）を `NEXT_PUBLIC_EBOOK_URL` に設定すると、サイトのトップと診断結果に本の紹介枠が出る
- 出版直後に5日間の無料キャンペーン（KDPセレクトの機能）を使い、レビューとランキングを先に作る
- 売れ行きを見て、「醤油編」「味噌編」などテーマ別の続編を出す（同じ手順で量産できる）
