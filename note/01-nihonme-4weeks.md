# 調味料の「2本目」で失敗しない4週間プラン

気になる醤油を買ってみた。最初の数日は楽しく使った。でも気づけば冷蔵庫の奥で、半分以上残ったまま賞味期限が近づいている。

調味料を変えてみたい人がつまずくのは、たいてい「どれを買うか」ではなく、**買ったあと**です。いつもの1本がある以上、新しい1本は意識しないと使われません。結局「やっぱりいつものでいいか」となり、2本目を買うこと自体が億劫になっていきます。

この記事は、その失敗をしないための**4週間の段取り表**です。

- 最初にどの調味料から変えると効果が大きいか（優先順位の決め方）
- 予算と容量の決め方、買うときのルール
- 1週間に1カテゴリずつ進める、毎日の献立割り当て表
- 減りが遅いときの「使い切りレシピ」4品
- 4週間後に「定番を入れ替えるか」を決める判定シート

調味料の種類や味の違いの解説はしません。それは本やサイトでいくらでも読めます。ここに書くのは、**今週末に買いに行って、4週間後に1本も余らせず、自分の定番が1つ決まっている**ための手順だけです。

## 1. 最初の1本は「使う回数 × 違いの出やすさ」で決める

2本目を買うとき、多くの人は「気になったもの」から手を出します。でも、使う機会が少ない調味料を変えても違いを感じる回数が少なく、使い切れずに終わりがちです。

おすすめの順番は、**使う回数が多く、料理に味の差が出やすいもの**からです。

| 順番 | カテゴリ | 理由 |
|---|---|---|
| 1 | 醤油 | ほぼ毎日使い、かける・つける使い方が多いので違いがそのまま舌に届く |
| 2 | 味噌 | 味噌汁なら毎日でも使える。1回の使用量が多く、使い切りやすい |
| 3 | 塩 | 下味では差が出にくいが、仕上げにふると違いがはっきりする |
| 4 | 酢 | 使う頻度に個人差が大きい。習慣がない人は後回しでいい |
| 5 | 砂糖 | 料理での差は小さめ。お菓子や飲み物をよく作る人だけ優先 |

ただし、これは平均的な家庭の目安です。**自分の台所で1週間、どの調味料を何回使ったかを数えてみる**と、自分の順番が分かります。冷蔵庫の扉にメモを貼り、使うたびに「正」の字を書くだけで十分です。

味噌汁を毎朝作る家なら味噌が1番になり、サラダを毎晩食べる家なら酢が上に来ます。回数が一番多いカテゴリから始めてください。

## 2. 買い物のルールは5つだけ

### ルール1　1回に買うのは1カテゴリ1本

醤油と味噌を同時に変えると、料理の味が変わった理由が分からなくなります。**1週間に変えるのは1カテゴリだけ**にします。

### ルール2　いつもの1本は捨てずに残す

新しい1本を評価するには、比べる基準が必要です。いつもの1本は「ものさし」として残しておき、同じ料理で交互に使います。

### ルール3　容量は「4週間で使い切れる量」を選ぶ

目安は次のとおりです。迷ったら小さいほうを選びます。

| カテゴリ | 2本目の容量の目安 |
|---|---|
| 醤油 | 200〜300ml程度の小瓶・小ボトル |
| 味噌 | 300〜500g程度 |
| 塩 | 100g前後（仕上げ用なら少なくて十分） |
| 酢 | 300〜500ml程度 |

いつもの1本と並行して使うので、家族の人数が多くても小さいサイズで足ります。

### ルール4　予算は先に決めてから店に行く

こだわりの調味料は、いつもの商品の数倍の値段がつくことも珍しくありません。店頭で迷うと、つい「せっかくだから」と高いほうを手に取ってしまいます。

**1本あたりの上限額を、家を出る前に決めておきましょう。** 4週間で4本買うなら、月の上限は「1本の上限 × 4」です。食費の中でいくら使うかを決めてから始めると、続けやすくなります。

高い1本がいちばん好みに合うとは限りません。上限額の中で、**いつもの1本とタイプがはっきり違うもの**を選ぶほうが、違いを楽しめます。

### ルール5　開封日を書く

マスキングテープに開封日を書いて、ボトルに貼ります。4週間のどこまで来たか、どれくらい減ったかが一目で分かり、使い忘れを防げます。

## 3. 4週間の献立割り当て表

ここからが本題です。2本目を買ったら、**その週の毎日、どの料理で使うかを先に決めておきます。** 「気が向いたら使う」では、まず使われません。

表の「新」は新しい1本、「いつも」はいつもの1本です。両方を使う日は、同じ料理を2つに分けて食べ比べます。

### 第1週　醤油

| 曜日 | 料理 | 使い方 |
|---|---|---|
| 月 | 卵かけご飯 | 新 |
| 火 | 焼き魚（大根おろし添え） | 新といつもを半分ずつ |
| 水 | 野菜炒め | 新（仕上げに回しかける） |
| 木 | 納豆 | 付属のたれを使わず、新を数滴 |
| 金 | 刺身または漬けまぐろ | 新といつもで食べ比べ |
| 土 | 焼きおにぎり | 新を塗って焼く |
| 日 | 使い切りレシピ「味玉」（後述） | 新 |

醤油は「加熱しない使い方」で違いが一番よく分かります。月・木・金のように、最後にかけたり、つけたりする料理を多めに入れています。

### 第2週　味噌

| 曜日 | 料理 | 使い方 |
|---|---|---|
| 月 | 豆腐とわかめの味噌汁 | 新 |
| 火 | 味噌汁 | 新といつもを半量ずつ合わせる |
| 水 | 野菜スティック（味噌マヨ） | 新 |
| 木 | 豚肉と野菜の味噌炒め | 新 |
| 金 | 味噌汁 | いつも（新との違いを思い出す日） |
| 土 | 使い切りレシピ「豚の味噌漬け焼き」（後述） | 新 |
| 日 | 具だくさん豚汁 | 新 |

火曜日のように**いつもの味噌と合わせて使う**と、新しい味噌が強すぎたときにも使い切れます。好みの配合が見つかれば、それが自分だけの合わせ味噌になります。

### 第3週　塩

| 曜日 | 料理 | 使い方 |
|---|---|---|
| 月 | 塩むすび | 新 |
| 火 | トマトのスライス | 新といつもで食べ比べ |
| 水 | 焼いた鶏肉 | 下味はいつも、仕上げに新をひとつまみ |
| 木 | 冷やしきゅうり（塩もみ） | 新 |
| 金 | 天ぷらや唐揚げなどの揚げ物 | 新をつけて食べる |
| 土 | 焼き野菜（オリーブオイルと） | 新 |
| 日 | 使い切りレシピ「即席浅漬け」（後述） | 新 |

塩は**下味ではなく仕上げに使う**のがポイントです。下味に使うと、料理の中で他の味と混ざって違いが分からなくなります。

### 第4週　酢（または自分の順番で4番目のカテゴリ）

| 曜日 | 料理 | 使い方 |
|---|---|---|
| 月 | わかめときゅうりの酢の物 | 新 |
| 火 | 餃子のたれ（酢＋こしょう） | 新といつもで食べ比べ |
| 水 | 手作りドレッシングのサラダ | 新 |
| 木 | 鶏肉のさっぱり煮 | 新 |
| 金 | 使い切りレシピ「ピクルス」（後述） | 新 |
| 土 | 焼きそば・ラーメンに数滴 | 新 |
| 日 | 振り返り（次の章の判定シート） | ― |

酢を使う習慣がない人は、第4週を砂糖や、みりん・ポン酢など自分がよく使う別の調味料に置き換えてかまいません。

### 表どおりにいかない日は

外食や残り物の日があっても、気にせず翌日に回してください。大事なのは**1週間で5回以上、新しい1本を使うこと**です。それだけ使えば、好きか、そうでもないかははっきりします。

## 4. 減りが遅いときの使い切りレシピ4品

週の終わりにまだ残っているときは、たくさん使うレシピで一気に減らします。どれも「漬けて置いておくだけ」なので、平日でも作れます。

### 味玉（醤油を多めに使う）

1. 卵4個を沸騰した湯で6〜7分ゆで、冷水で冷やして殻をむく
2. 醤油・みりん・水を同量ずつ（各大さじ3程度）合わせ、みりんのアルコールが気になる場合は小鍋でひと煮立ちさせて冷ます
3. ポリ袋に卵と漬け汁を入れ、空気を抜いて冷蔵庫で一晩

翌日から2日ほどで食べ切ってください。

### 豚の味噌漬け焼き（味噌を多めに使う）

1. 味噌大さじ2、みりん大さじ1、砂糖小さじ1を混ぜる
2. 豚ロース（とんかつ用）2枚の両面に塗り、ラップで包んで冷蔵庫で半日〜1日置く
3. 味噌を軽くぬぐい、焦げやすいので弱めの中火で両面を焼く

### 即席浅漬け（塩を多めに使う）

1. きゅうり2本、キャベツ数枚を食べやすく切る
2. 野菜の重さの2%程度の塩（野菜300gなら塩小さじ1強）と一緒にポリ袋に入れてもむ
3. 冷蔵庫で30分〜1時間置き、水気を絞る

塩の違いは、シンプルな浅漬けだとよく分かります。

### ピクルス（酢を多めに使う）

1. 酢100ml、水50ml、砂糖大さじ2〜3、塩小さじ1/2を小鍋で温めて溶かす
2. にんじん、パプリカ、大根などを棒状に切って清潔な保存瓶に入れる
3. 1を熱いうちに注ぎ、冷めたら冷蔵庫へ。翌日から食べられます

冷蔵庫で保存し、1週間程度を目安に食べ切ってください。

## 5. 4週間後の判定シート

最後の日曜日に、4本それぞれについて次の5つの質問に答えます。紙に書いても、スマホのメモでもかまいません。

| 質問 | 醤油 | 味噌 | 塩 | 酢 |
|---|---|---|---|---|
| ① 新しい1本を、もう一度お金を出して買いたいか（はい／いいえ） | | | | |
| ② 家族や同居人の反応はどうだったか（好評／普通／不評） | | | | |
| ③ 一番おいしいと感じた料理は何か | | | | |
| ④ 1か月で使い切れたか（使い切った／半分以上残った） | | | | |
| ⑤ いつもの1本と比べた値段の差は、納得できるか（はい／いいえ） | | | | |

判定のルールはシンプルです。

- **①と⑤が両方「はい」** → 次から定番をこの1本に入れ替える
- **①は「はい」、⑤は「いいえ」** → 定番はいつものまま。③の料理のときだけ使う「専用の1本」にする
- **①が「いいえ」** → 今回は見送り。同じカテゴリで、タイプの違う別の1本を次に試す

④で「半分以上残った」場合は、容量が大きすぎたか、使う料理が合っていなかったサインです。次は容量を小さくするか、③の料理を中心に使う計画を立ててください。

## 6. 2か月目からの続け方

4週間で、少なくとも1つのカテゴリで「自分の定番」か「専用の1本」が決まっているはずです。2か月目は、判定シートで「見送り」になったカテゴリをもう一度、別のタイプで試してみましょう。

同じ手順を3か月続けると、台所の調味料はほとんど「自分で選んだもの」に入れ替わります。最初の1本で迷うことは、もうなくなっているはずです。
