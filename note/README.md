## Kindle本（KDPセレクト）とのすみ分けルール

KDPセレクトに登録している間は、Kindle本の内容を他の場所で電子的に配布・販売できません（一部の抜粋も含めて、本の内容を別媒体に載せない）。noteでは次のルールを守ります。

1. **本の文章・表・章構成をそのまま、または言い換えただけで載せない**
2. 本が扱うのは「種類・違い・食べ比べの手順・ラベル・保存」。noteは**買い方・段取り・献立・使い切り**など、本にない実践の話だけを書く
3. 本の紹介は記事末尾にタイトルとリンクを置くだけにする
4. サイトの無料記事（醤油の種類・食べ比べ方・使い分け）と同じ切り口にもしない。有料にする理由がなくなるため

## 投稿手順

1. note で「テキスト」の新規投稿を作り、原稿の本文をコピーして貼る（先頭の `---` で囲まれた部分は貼らない）
2. 「（ここから有料）」の位置に有料エリアの境界線を移動し、その行は削除する
3. 表がそのまま表示されない場合は、表の部分を箇条書きに直すか画像にする
4. 公開設定で「有料」を選び、価格を300円にする
5. ハッシュタグは原稿先頭の `hashtags` を使う
6. Kindle本の出版後・サイト公開後に、末尾の「※〜URLを入れる」の部分を実際のURLに差し替える
