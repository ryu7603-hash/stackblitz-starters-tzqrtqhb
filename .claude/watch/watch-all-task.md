# 全体ウォッチ（停滞チェック）— 定期タスク案

- 実行時刻: 毎日 10:23 / 14:23 / 19:23（日本時間）。朝夕の投稿タスクが終わった後に確認する
- 毎回新しいセッションで実行し、終わったらスマホに通知する
- 使うもの: Claude Code Remote（タスクとセッションの確認・再実行）、Claude in Chrome（ChatGPTとの協議）

## 毎回やること
1. 前回のウォッチの報告を読み、返事待ちの件は状況が変わらない限り繰り返さない
2. 全スケジュールタスクの直近の結果を読む（記録上「成功」でも「できていません」「止められました」「ログイン切れ」「CAPTCHA」「上限」を含めば停滞として扱う）。あわせて失敗したセッションと、GitHub の PR の CI も見る
3. 停滞があれば、Chrome の ChatGPT に原因と案を相談する（パスワード・トークン・ID は送らない）。使えなければ自分だけで判断する
4. 判断のいらないものは黙って進める
   - 一時的な失敗のタスクを1日1回まで再実行する
   - 手順の機械的な誤りの最小限の修正（修正前と修正後を報告する）
   - 自分のブランチの CI 修正
5. 次の場合だけ具申する
   - 本人の操作が必要（ログイン、CAPTCHA、最後のクリック、設定変更）
   - 方針の判断が必要
   - 3回続けて直らない

## やらないこと
- 安全チェック・CAPTCHA・ログインの回避
- 投稿・送信・購入・削除の代行
- 課金
- タスクの追加・削除・無効化
- 「しない」の決まりや権限に関わる指示文の変更
