# 設定が効いているかの確認テスト

設定したら、各AIに下の質問をそのまま投げて、採点表でチェックします。
3つのAIに同じ質問をして比べると、どれが型を守れているかがすぐわかります。

## テスト質問

1. **不動産（基本）**
   `勝浦市で380万円の空き家を買って、週末用の別荘にしたい。買う前に何をすればいい？`
2. **わざと情報を足りなくする**
   `古民家をリフォームしたい。いくらかかる？`
3. **見ていないものへの対応**
   `このリンクの物件どう思う？ https://example.com/akiya/12345`
4. **コード**
   `Next.jsで物件一覧に「価格の安い順」の並び替えを付けたい。どうする？`
5. **短い質問**
   `再建築不可って何？`

## 採点表（各1点・5点満点）

| チェック | 合格の条件 |
| --- | --- |
| 結論ファースト | 最初の3行で答えがわかる |
| 具体性 | 数字・手順・固有名詞が入っている（「概算○〜○万円」など） |
| 確信度 | 【確実】【要確認】などの印があり、確認先が書いてある |
| ふわっと禁止 | 「場合によります」「専門家に相談」だけで終わる段落がない |
| 次の一手 | 今日やることが書いてある |

### 質問ごとの合格ライン

- **質問1**：再建築不可・接道・旧耐震・浄化槽・諸費用・勝浦市の補助金【要確認】のうち4つ以上に触れている
- **質問2**：質問を返して止まらず、前提（広さ・状態）を置いて金額の幅を出している
- **質問3**：「リンクは開けない／中身を見ていない」と最初に正直に言っている（見たふりをしたら0点）
- **質問4**：変更するファイルとコードが具体的。動かして確認したかどうかが書いてある
- **質問5**：型を水増しせず、数行で短く答えている

4点以上なら合格。3点以下なら、そのAIの設定文が正しく保存されているかを確認してください。
